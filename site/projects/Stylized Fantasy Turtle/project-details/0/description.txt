I created this asset for a game called Turtle Town, where one controls a giant turtle while also managing and building a city on its back.

I sculpted and retopologized the turtle model in ZBrush, painted the textures in Substance Painter, and rigged it in Maya LT.

The screenshots you see are in Unity engine with orthographic projection, as was the intended display configuration for the game.

The turtle is rendered using a stylized shader which gives an outline effect as well as quantized lighting bands.
